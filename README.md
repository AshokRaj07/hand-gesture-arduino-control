# Hand Gesture Arduino Control

A beginner-level computer vision project that uses a webcam
to detect hand gestures and communicate with an Arduino.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PySerial
- Arduino

## How It Works

1. Webcam captures the user's hand.
2. MediaPipe detects hand landmarks.
3. Python checks whether the fingers are open.
4. Python sends a signal to Arduino through serial communication.
5. Arduino performs an action based on the received signal.
